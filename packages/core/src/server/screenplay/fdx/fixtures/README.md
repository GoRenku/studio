# FDX Import Fixtures

`representative.fdx` is a synthetic screenplay fixture authored for Renku
Studio. It is not derived from a copyrighted screenplay and is licensed under
the repository's MIT license.

The fixture intentionally covers ordered Text runs, XML entities, opening
content, retained-only Final Draft planning paragraphs, Scene numbers,
multi-part Dialogue, Parentheticals, cue extensions, Dual Dialogue,
production-tag evidence, and an ignored ScriptNote. Planning paragraphs are
included to prove that they do not create Renku hierarchy; this is not an
official Final Draft conformance fixture. It does not claim compatibility with
every Final Draft version or proprietary extension.
