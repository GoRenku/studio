# 0097 Use agent-directed scene segmentation

Date: 2026-09-11
Status: accepted

Skills plan complete ordered speech and action across the selected provider's live
limits. They inspect actual output before preparing a dependent continuation;
elapsed duration never proves coverage. Engines owns provider request validation
and execution. Core owns Project metadata and records optional source attribution,
not generation suitability or reference requirements.

For authorized multi-clip work, narrow ADR 0090's whole-selected-Take rule: a request
may use its assigned unretimed excerpts from the exact selected recordings. Preserve
originals and selection, keep separate Takes separate, record source intervals and
submitted offsets, and account for all requested speech across the scene. This does
not authorize silent truncation, voice replacement, time stretching or unselected
substitutes. Other workflows retain the whole-Take rule.

Previs is intentionally simple. It supplies spatial/camera/motion direction, not
finished surfaces, faces, wardrobe textures, prop artwork or rendering style.
Establish independent finished-look references, including featured inserts when
needed, and inspect the whole output for proxy reversion.

Raw clips are reviewed without automatic editing. Timing may differ from Previs
unless explicitly locked; missing speech, voice identity and mouth synchronization
are separate review dimensions. Changes to clips/selection do not automatically
regenerate footage. Existing approval, provenance and Asset contracts apply.

Operational guidance lives in Studio Skills' Media Producer scene-segmentation
reference. Plans 0203 and 0204 own implementation; no runtime creative validator,
provider timeline, editing surface or generation scheduler is introduced.
